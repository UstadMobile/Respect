Open Educational Experience Launcher Demo App

If you're here, you're probably thinking about making your app work with an Open Educational Experience Launcher e.g. Respect. See README_ADD_YOUR_APP.md on GitHub for more info.

This demo app includes an OPDS collection of learning units as per the README. Each learning unit can send xAPI usage data back to the launcher.

  • Launchable app manifest: app_manifest.json
  • Default collection: default-collection.json
